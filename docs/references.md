# 参考文献 / References

工具栏“参考文献 [n]”接受网址、DOI 和文本，在当前光标处插入引用。侧栏列出当前文献，可以再次引用或跳转文末。点击正文标号打开侧栏；预览和阅读页中点击标号跳转文末，文末编号返回最近点击的引用位置。

草稿新文献递增编号，移动与删除不重排，同一文献复用编号。当前编辑会话保留删除记录和编号高水位；重新打开文档以仍存在的引用初始化。发布通过宿主 publishForLifecycle 方法按首次出现顺序生成连续编号，成功且草稿没有新编辑时回写。失败保留本地草稿；NWU 宿主另保存恢复草稿。一般保存、预览、导出不重编号。

源码格式为 `[数字](#wref-稳定ID~URL编码的文献原文)`。每个引用自包含，复制部分文档不会丢失定义。Markdown 导出保留此格式，W-Editor 重开后派生文末列表；HTML 等渲染导出包含文末列表。普通第三方 Markdown 阅读器不自动生成这份文末列表。

普通输入只映射已有引用位置，不全文重编号；文献列表仅在引用内容/顺序变化时重建。无输入期间网络请求，也不自动获取 DOI 元数据。首次打开、插入引用和发布会扫描源码。

Windows 独立软件的发布入口接入、打包与运行验证留待 Windows 环境；此次只更改共享核心、Vue/Playground 和已有 NWU Web 宿主。
