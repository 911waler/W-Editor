# Toolbar command and associated component parity matrix

This companion expands the checked 80-command inventory in `docs/toolbar-command-matrix.md`. Stable command ID is the join key: the original inventory remains the exact command/source/outcome record, while this matrix freezes reference ownership and the presentation and interaction dimensions that must be audited. Component profile IDs in command rows resolve to the detailed associated-component rows below.

The row order is normative. “Cherry toolbar” means the reviewed top main/right toolbar; “Cherry Final” means the pinned Cherry 0.11.9 rendering contract. “Tiptap Visual” means the locally frozen Notion-like editing reference implemented with W-Editor's published Tiptap 3.30.2 packages. Reference assets and numeric capture metadata are frozen separately by Task 19.3.

## Frozen Cherry top-toolbar contract

The shared principal order is `text.bold` → `text.italic` → `menu.text-style` → `text.size` → `menu.color` → `menu.heading` → `insert.drawio` → `list.ordered` → `list.unordered` → `list.task` → `menu.panel` → `layout.timeline` → `menu.alignment` → `layout.accordion` → `insert.formula.alias` → `menu.insert` → `menu.mermaid` → `menu.chart` → `history.undo` → `history.redo` → `settings.shortcuts` → `search.replace` → `mode.preview.alias` → `document.manual-save` → `spacer` → `line-spacing` → `document.word-count` → `menu.theme` → `menu.language` → `menu.export` → `application.fullscreen`. The separators and flexible right spacer shown by the frozen reference remain in those same family boundaries; `line-spacing` is a W-Editor non-command appearance extension immediately left of Word count.

The Text style menu owns Strike, Underline, Subscript, Superscript, and Ruby/Pinyin. Color owns text and background color; Heading owns H1–H5; Panel owns five panel variants plus W-Editor's approved two-column, multi-column, and Tabs extensions; Accordion remains a direct control. Insert owns the fourteen insertion commands including Formula and Table; Formula additionally has the shared Cherry top-level alias. Mermaid and Chart are separate adjacent controls, not one W-Editor Draw menu. Theme, Language, and Export remain right-side menus.

The visual tokens are the Cherry 0.11.9 values: `4px 24px` toolbar padding, `14px` toolbar and icon size, `38×38px` controls, `0 12px` control padding, `6px` control radius, and `2×21px` separators with `4px` inline margins. Shared controls render the shipped `ch-icon` icon-font classes and their `::before` glyphs; textual Cherry controls remain text. The full Cherry sans-serif stack is normative.

W-Editor-only behavior is explicit: Undo and Redo occupy the two positions where the reviewed demo adds non-product custom controls; Save version follows the Cherry Preview position; Panel retains the three approved product layout entries; Source/Visual/Final remain the authoritative non-sticky mode controls while `mode.preview.alias` mirrors Preview in the toolbar. The approved `menu.theme` appearance preference mirrors Cherry 0.11.9's eight main themes across the entire W-Editor shell and persists independently of Markdown; its radio choices are not document commands and do not change the frozen 80 stable command identities.

## Scope and exception rules

- The named profiles cover every component family reached by the 79 command rows plus contextual Quote and the three active surfaces. A command may reference multiple profiles, but it still has exactly one stable command row.
